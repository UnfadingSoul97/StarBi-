## ⭐StarBi-⭐
A pet to be a pet.
----
This is a small project on making a digital pet.
I liked this project and it was fun to do and i hope to work towards my goals and dreams and am taking this oppertunity to make the most of it.

----
This project entails a star shaped PCB with
1.An oled display.
2.2 Cherry MX Swithes.
3.A Temp,Humidity and motion.
4.A Micro Controler for the system.
5.Another micro contoler suitable for the sensor.
